2. DRIVER INSTALLATION LOCATION
   =============================
   ✓ YES - Drivers are installed on the SAME PC (your PC)
   ✗ NOT on target/victim PC
   
   Why? The JTAG port connects back to YOUR motherboard via USB:
   
   [Your PC]
      ├─ PCIe Slot ──→ [DMA Card] ──→ Target PCIe slot on other PC
      └─ USB Port ←──┐                (for DMA attacks)
                     │
                     └─ JTAG/Update Port (on DMA card)
                        (for programming/DNA extraction)

5. POWERSHELL COMMANDS FOR YOUR C++ CODE
   ======================================
   
   Check Driver Status:
   -------------------
   Get-PnpDevice | Where-Object {\.FriendlyName -like "*CH347*"}
   
   Get Driver Version:
   ------------------
   Get-PnpDeviceProperty -InstanceId <id> -KeyName "DEVPKEY_Device_DriverVersion"
   
   Install Driver:
   --------------
   pnputil.exe /add-driver "path\to\driver.inf" /install
   
   Uninstall Driver:
   ----------------
   pnputil.exe /delete-driver oem154.inf /uninstall /force
   
   Check Admin Rights:
   ------------------
   ([Security.Principal.WindowsPrincipal][Security.Principal.WindowsIdentity]::GetCurrent()).IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)
