HOW TO DETECT CHIP TYPE (35T/75T/100T):
========================================

Read the IDCODE register via OpenOCD JTAG scan.

IDCODE to Chip Mapping:
-----------------------
0x03622093 = XC7A35T   (Artix-7 35T)
0x0362D093 = XC7A75T   (Artix-7 75T)
0x03631093 = XC7A100T  (Artix-7 100T)

Note: First digit may be 0x0 or 0x1 (version/stepping)
Example: 0x13631093 = XC7A100T (version 1)

The part number is in bits [27:12] of IDCODE:
- 0x3622 = 35T
- 0x362D = 75T
- 0x3631 = 100T


HOW TO DETECT INTERFACE TYPE (CH347 vs RS232):
===============================================

METHOD 1: Check OpenOCD Executable/Config Used
-----------------------------------------------
CH347:  Uses openocd-347.exe with ch347 driver
        Config: init_347_*.cfg
        VID/PID: 0x1a86 0x55dd (or 0x55de)

RS232:  Uses openocd.exe with ftdi driver
        Config: init_232_*.cfg
        VID/PID: 0x0403 0x6011 (35T) or 0x0403 0x6014 (75T)

METHOD 2: Check USB Devices (Windows)
--------------------------------------
CH347:  Device shows as 'USB HighSpeed-JTAG/I2C... CH347T'
        Manufacturer: WCH
        
RS232:  Device shows as FTDI-based serial adapter
        Manufacturer: FTDI


COMPLETE DETECTION WORKFLOW:
=============================

Step 1: Detect Interface Type
------------------------------
Query USB devices:
  PowerShell: Get-PnpDevice | Where-Object {$_.FriendlyName -like '*CH347*' -or $_.FriendlyName -like '*FTDI*'}

If CH347 found:
  - Use: openocd-347.exe
  - Config base: init_347_
  
If FTDI found:
  - Use: openocd.exe
  - Config base: init_232_


Step 2: Detect Chip Type
-------------------------
Run OpenOCD with any config (doesn't matter which chip config):
  openocd-347.exe -f init_347_75t.cfg

Parse output for line:
  'JTAG tap: xc7.tap tap/device found: 0xXXXXXXXX'

Extract IDCODE and map to chip type:
  0x?3622093 → XC7A35T
  0x?362D093 → XC7A75T  
  0x?3631093 → XC7A100T


Step 3: Extract DNA ID
-----------------------
Same OpenOCD output contains:
  'DNA = <binary> (0xXXXXXXXXXXXXXXXX)'

Extract the hex value: 0x003ccd8c77d04854
