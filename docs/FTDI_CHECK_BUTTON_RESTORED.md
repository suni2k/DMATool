## Button Functionality

### Check Driver Status Button
- **Action**: Queries Windows for FTDI device status
- **Progress**: Shows "Querying driver status..." in popup
- **Output**: Logs driver info (version, device name, VID/PID)
- **Threading**: Runs synchronously with 2-frame delay

### Install FTDI Driver Button
- **Action**: Installs FTDI WinUSB driver from embedded resources
- **Progress**: Shows live installation progress in popup
- **Output**: Logs installation steps and final status
- **Threading**: Runs on separate thread (non-blocking)

### Uninstall FTDI Driver Button
- **Action**: Removes FTDI WinUSB driver using pnputil
- **Progress**: Shows live uninstallation progress in popup
- **Output**: Logs removal steps and final status
- **Threading**: Runs on separate thread (non-blocking)
